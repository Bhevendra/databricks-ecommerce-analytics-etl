# etl-ecommerce-analytics Documentation

This repository contains the Databricks bundle, Data Engineering jobs, and deployment workflows for the etl-ecommerce-analytics project.

Structure:
- `resources/`: Databricks jobs, clusters, permissions, quality checks, and pipelines definitions.
- `src/`: notebooks and shared code.
- `tests/`: unit, integration, and data quality tests.
- `monitoring/`: observability checks and SLA definitions.
- `environments/`: environment-specific deployment variables.
- `.github/workflows/`: CI/CD deployment pipelines.
